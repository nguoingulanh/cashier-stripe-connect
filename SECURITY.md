# Security Policy

Please **do not** report security vulnerabilities through public GitHub issues.

Report them privately through [GitHub Security Advisories](https://github.com/nguoingulanh/cashier-stripe-connect/security/advisories/new). You will receive a response as soon as possible, and a fix will be released for all supported versions.

## Supported versions

| Version | Supported |
|---------|-----------|
| 1.x     | ✅        |
